# 📖 About

BazaarNepal is a modern e-commerce application built to simulate a real online marketplace in Nepal.

The application includes separate experiences for customers and sellers. Customers can browse products, manage their shopping cart, apply promotional discounts, and complete purchases through eSewa. Sellers can manage inventory, create promotional campaigns, monitor sales, and track business performance from an analytics dashboard.

The project was built to strengthen my full-stack development skills while focusing on modern React architecture, reusable components, responsive design, and practical business workflows.

# 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/dikeshsapkota/BazaarNepal.git
```

### Navigate into the project

```bash
cd BazaarNepal
```

### Install dependencies

```bash
npm install
```

### Run the development server

```bash
npm run dev
```

Open your browser at:

```
http://localhost:5173
```
