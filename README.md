# 🛍️ BazaarNepal

### Modern Full-Stack E-Commerce Platform for Nepal 🇳🇵

A scalable and responsive e-commerce platform built with modern web technologies, featuring secure authentication, product management, shopping cart, order processing, and a clean user experience.

## 🚀 Getting Started

### Clone Repository

```bash
git clone https://github.com/dikeshsapkota/BazaarNepal.git
```

### Navigate

```bash
cd BazaarNepal
```

### Install Dependencies

```bash
npm install
```

### Start Development

```bash
npm run dev
```
